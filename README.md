# 通知抽取助手 · Notice → Matter

> 把一段校园通知原文，自动抽成结构化数据：**截止时间、材料清单、办理步骤、风险预警**。
>
> 参赛作品 · **传智杯 AI WEB 网页开发挑战赛** ｜ 队伍：**Triple Y**

---

## 1. 项目简介

校园里的通知散落在群消息、公告栏、教务系统和各种 PDF 里，格式五花八门：有的只有一句「10月25日18:00前提交报名表」，有的是「填表 → 审核 → 缴费 → 打印准考证」这种多步骤流程，还夹着材料清单和责任人。

本项目把这类**非结构化通知原文**，通过大模型抽取成统一的 **Matter JSON**，并按通知的复杂度自动选择三档输出结构：

| 模式 | 触发条件 | 输出内容 |
| --- | --- | --- |
| `simple` | 只有 1 个时间点或 1 个动作 | 标题、截止时间、提醒、原文出处 |
| `standard` | ≥2 个步骤，或有材料清单 / 地点 / 附件 | 再加：材料清单、附件、步骤列表、地点 |
| `complex` | 有子步骤、前置依赖、多角色、审核环节、时间冲突、周期性 | 再加：风险预警、依赖关系、子步骤、审核人、循环规则 |

复杂度由**确定的评分公式**计算（不是让模型随便说），保证同一份通知的输出稳定、可解释、可复现。

---

## 2. 功能特性

- **三档自适应输出**：`simple / standard / complex` 由评分公式 + 判定规则决定，`simple` 绝不会出现材料/步骤等字段（`enforce_mode` 强制裁剪）。
- **只抽原文有的信息**：原文没提到的字段直接省略，不允许编造地点、负责人、材料。
- **相对时间归一化**：把「下周三」「明天下午3点」按服务端当前时间（`NOW`）归一化成 `ISO 8601 + 08:00` 的绝对时间。
- **字段级溯源**：关键字段带 `source_ref.quote`，可回溯到原文片段。
- **Mock / 真实双模式**：无 API Key 时自动降级为虚构数据，前端页面不必等模型就绪就能开发；配好 Key 即切换真实模型。
- **接口层的健壮性**：CORS 全放开、统一响应契约（永远 HTTP 200 + `{success,data,error}`）、空文本与超长文本校验、异常兜底，前端不会拿到 500 堆栈。
- **可自检可回归**：`check_env.py`（环境自检）、`test_llm.py`（密钥连通性）、`smoke_test.py`（10 项接口回归）。

## 3. 技术架构

```
┌──────────────────────┐        HTTP / JSON（CORS 全放开）
│  前端 Web 页面（B）   │  ─────────────────────────────────┐
│  粘贴通知 / 查看结果   │  POST /api/analyze {text}         │
└──────────────────────┘  ◀─────────────────────────────────┘
                                                             │
                                    ┌────────────────────────▼─────────────────────────┐
                                    │  后端服务（C）FastAPI · Python                       │
                                    │  main.py：CORS / 参数校验 / 统一响应 / GET /health   │
                                    └────────────────────────┬─────────────────────────┘
                                                             │  analyze_notification(text)
                                    ┌────────────────────────▼─────────────────────────┐
                                    │  抽取服务（A）service.py                           │
                                    │  SYSTEM_PROMPT（模式规则 / 字段互斥 / 字段口径）      │
                                    └────────────────────────┬─────────────────────────┘
                                                             │
                                    ┌────────────────────────▼─────────────────────────┐
                                    │  notification_extractor.py                        │
                                    │  LLMClient（OpenAI 兼容 / Mock 降级）               │
                                    │  MatterExtractor：复杂度重算 → 模式判定 → 字段裁剪   │
                                    │  → JSON Schema 校验 → Matter 对象（含提醒调度）      │
                                    └──────────────────────────────────────────────────┘
```

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 后端框架 | FastAPI + Uvicorn | 单文件入口 `backend/main.py`，接口文档自动生成（`/docs`） |
| 数据校验 | Pydantic | 请求/响应模型 + 入口参数校验 |
| 抽取模型 | OpenAI 兼容接口（默认 `gpt-4o`，可换 `LLM_BASE_URL` / `LLM_MODEL`） | 低温度 + JSON 输出模式，保证结构化 |
| 结构化保障 | 自研评分公式 + `enforce_mode` + JSON Schema（`jsonschema`） | 不信模型给的分档，服务端重算并裁剪字段 |
| 配置 | python-dotenv + 环境变量 | `.env.example` 为模板，密钥不入库 |
| 前端 | 见 `frontend/`（B 负责，技术栈待补充） | 通过 `VITE_API_BASE_URL` 指定后端地址 |

## 5. 快速开始（后端）

```powershell
cd backend

python -m venv .venv
.\.venv\Scripts\Activate.ps1          # Windows；macOS/Linux：source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env                # macOS/Linux：cp .env.example .env

python check_env.py                   # 环境自检（推荐先跑，看到「环境就绪 ✅」再往下）
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

- 服务状态：<http://127.0.0.1:8000/health> → `{"status":"ok","mode":"mock"}`
- 接口文档：<http://127.0.0.1:8000/docs>
- 接口自测：另一个窗口执行 `python smoke_test.py`

详细说明（含密钥配置、局域网联调、常见问题）见 **[docs/环境配置与运行说明.md](docs/环境配置与运行说明.md)** 和 **[backend/README.md](backend/README.md)**。

## 6. 环境变量（速查）

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `LLM_ENABLE_MOCK` | 否 | `1` = 无 Key 时返回虚构数据（联调用），`0` = 关闭 |
| `LLM_API_KEY` | 生产必填 | 大模型 API Key；留空 + Mock=1 → 走 mock |
| `LLM_BASE_URL` | 否 | 默认 `https://api.openai.com/v1`，换平台时改这里 |
| `LLM_MODEL` | 否 | 默认 `gpt-4o` |
| `PORT` | 否 | 默认 `8000` |
| `MAX_TEXT_LENGTH` | 否 | 文本长度上限，默认 `3000` 字符；`0` = 不限制 |

> ⚠️ **密钥安全**：`.env` 已在 `.gitignore` 中，任何情况下都不要把真实 Key 提交到仓库（比赛明确要求）。
