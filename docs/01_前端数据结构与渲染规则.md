# 前端数据结构与渲染规则

## 1. 顶层控制字段

| 字段 | 用途 |
|---|---|
| `mode` | 决定整体 UI 复杂度：simple / standard / complex |
| `enabled_sections` | **决定要渲染哪些区块（最重要，见下表）** |
| `title` | 顶部大标题 |
| `priority` | 用不同颜色标识（low 灰 / medium 蓝 / high 橙 / urgent 红） |
| `status` | 事项状态徽章 |
| `complexity_score` | 可选：右上角小标签 |

## 2. enabled_sections 与区块对应

| section 值 | 对应区块 | 主要字段 |
|---|---|---|
| `summary` | 摘要卡 | `title` / `background` / `target` / `category` / `priority` |
| `schedule` | 时间与提醒 | `deadline` / `reminders` |
| `content` | 要点与附件 | `key_points` / `attachments` |
| `steps` | 步骤流程 | `step_list` |
| `materials` | 材料清单 | `materials` |
| `warnings` | 预警提示 | `warning_list` |
| `governance` | 权限与协作 | `permissions` / `audit_log` / `comments` |
| `source` | 原文出处 | `sources` |

> **渲染规则**：只画 `enabled_sections` 里出现的区块。
> - simple 模式只有三块：`summary`、`schedule`、`source`
> - standard 模式增加：`content`、`steps`、`materials`
> - complex 模式增加：`warnings`、`governance`
