# 各区块字段用途详解

## 区块 1：summary（摘要）

| 字段 | 展示建议 |
|---|---|
| `title` | `<h1>` 大标题 |
| `background` | 副标题或灰底说明文字 |
| `target.name` | 标签：面向：2026级本科生 |
| `category` | 标签：报名 |
| `priority` | 用颜色区分紧急程度 |
| `status` | 状态徽章：待开始 / 进行中 / 已完成 |

## 区块 2：schedule（时间与提醒）

| 字段 | 展示建议 |
|---|---|
| `deadline.due_at` | **倒计时卡片（最重要）** |
| `deadline.start_at` | 若存在，显示“开始时间” |
| `deadline.label` | “截止时间” |
| `reminders[].offset_minutes` | “提前 120 分钟提醒” |
| `reminders[].channels` | 图标：app / email |

> **倒计时计算**：`due_at - 当前时间`，格式化为“还剩 9 天 3 小时”。

## 区块 3：content（要点与附件）

| 字段 | 展示建议 |
|---|---|
| `key_points[]` | 带圆点的要点列表 |
| `attachments[]` | 下载按钮 / 链接 |

## 区块 4：steps（步骤流程）

| 字段 | 展示建议 |
|---|---|
| `step_list[].order` | 序号圆点 |
| `step_list[].title` | 步骤名 |
| `step_list[].status` | 勾选框：completed 打勾 |
| `step_list[].due_at` | 步骤 DDL |
| `step_list[].materials[]` | 关联材料（ID 数组 → 到 materials 里查名字） |
| `step_list[].sub_step_list[]` | **仅 complex**，缩进显示子步骤 |

> **继承规则**：`due_at` 为空且 `due_at_inherited_from` 为 `"overall"`，用顶层 `deadline.due_at`。

## 区块 5：materials（材料清单）

| 字段 | 展示建议 |
|---|---|
| `material_name` | 材料名 |
| `material_type` | `required` → 标“必填”；`optional` → 标“可选” |
| `status` | `pending` 未准备 / `uploaded` 已上传 / `submitted` 已提交 / `approved` 通过 / `rejected` 驳回 |
| `template_attachment_id` | 有值就显示“下载模板”按钮，去 `attachments` 里找 `attachment_url` |

## 区块 6：warnings（预警，仅 complex）

| 字段 | 展示建议 |
|---|---|
| `severity` | `low` / `medium` / `high` / `critical` → 不同颜色告警条 |
| `message` | 告警文字 |
| `action.suggestion` | 建议动作 |

## 区块 7：source（原文出处）

| 字段 | 展示建议 |
|---|---|
| `sources[].quote` | 引用原文片段 |
| `sources[].page` | 若存在，显示“第 X 页” |

> **提示**：所有区块里的 `source_ref.quote` 都可以做成悬浮提示或“查看原文”按钮。
