# 演示数据包（录视频 / 验收直接用）

| 文件 | 对应里程碑 | 演示要点 |
| --- | --- | --- |
| `01-标准通知-奖学金.txt` | 10/21、10/22 | 标准模式：截止时间、材料 3 项、步骤、查看依据 |
| `02-完整流程-社会实践.txt` | 10/21 | 完整流程模式：审核、依赖、地点、风险预警 |
| `03-材料视频通知.txt` | 10/18、10/19 | 用户情况核对：「没有视频」→ 指出缺视频；勾选材料 → 三类结果 |
| `04-通知截图.png` | 10/23 | 截图上传 → 本地 OCR / 视觉模型 → Matter |
| `05-文字型通知.pdf` | 10/25 | PDF 上传 → 文字提取 → Matter |

## 使用建议（录演示视频时）

1. 先粘贴 `01` → 展示标准模式结果 → 点「出处」看原文
2. 粘贴 `02` → 展示完整流程（流程树 / 预警）
3. 粘贴 `03` → 「我们队的情况」勾报名表、视频选"没有" → 提交核对 → 指出缺视频
4. 上传 `04-通知截图.png` → 截图解析
5. 上传 `05-文字型通知.pdf` → PDF 解析
6. 上传 `01`/`03` 到材料库 → 追问「视频有什么要求？」→ 回答附出处；再问「食堂几点开门？」→ 未找到依据

> `_gen_assets.py` 是生成截图/PDF 的脚本，可重复运行（换文案即可）。
