## 2. 关键实现

- `src/ai_error.py`：统一 `code / message / stage / retryable / request_id`；
  - 原始异常只写日志，响应只给可读提示；
  - `AI_NO_KEY` 保留 `LLM_API_KEY` 字样，兼容 C 侧既有 Mock 判断。
- `src/service.py`：
  - `analyze_notification` / 图片 / 对比 / RAG 的异常均走 `classify_exception`；
  - `workflow_trace` 不复制原文，只记录阶段、状态、耗时和模型名；
  - 写操作仍由用户确认，不由模型直接执行。
- `src/service.py#search`：
  - 材料外问题若只命中“申请/时间”等通用词，不返回结果；
  - 领域锚点 + 短语 + IDF/BM25 才进入 Top-K。

## 3. 边界

- 本测试不等于完整的 Web 安全审计；C 侧仍需做 CORS、文件系统、限流、会话隔离测试。
- 前端仍必须对 AI 输出做 `esc()` 转义；后端不输出 HTML。
- 没有真实用户数据；所有测试输入为虚构通知。
