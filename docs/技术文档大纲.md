## 写作要求

- 每个 AI 决策都要有"为什么"（选型理由 / 集成方式 / 优化策略），这是评分重点（AI 技术深度 35% + 创新性 25%）
- 架构图和流程图至少 3 张（系统架构、数据流、RAG 流程）
- 测试章节放真实数据：8 套自测的通过数、Mock 平均耗时、真实模型首次耗时
- 统一术语：Matter / 模式（simple/standard/complex）/ 缺项核对 / 查看依据 / 材料片段
