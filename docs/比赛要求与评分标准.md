## 2. 提交材料清单

### 2.1 代码仓库

| 要求项 | 具体要求 |
| --- | --- |
| 托管平台 | GitHub / Gitee（须设为 Public 或提供评审访问权限） |
| 代码规范 | 代码结构清晰，包含有效注释，遵循主流代码规范 |
| README | 包含项目介绍、技术架构、安装运行指南、团队信息 |
| Git 记录 | 保留完整的 Git 提交历史，体现真实的开发过程 |
| 环境配置 | 提供完整的环境配置说明（含环境变量模板、依赖清单） |

### 2.2 演示视频

| 要求项 | 具体要求 |
| --- | --- |
| 时长 | 5–8 分钟 |
| 内容 | 项目介绍、核心功能演示、AI 技术亮点展示 |
| 格式 | MP4，分辨率不低于 1080p |
| 语言 | 普通话讲解，可配字幕 |

### 2.3 技术文档

| 要求项 | 具体要求 |
| --- | --- |
| 格式 | PDF，不超过 30 页 |
| 内容 | 项目概述、需求分析、系统架构设计、AI 技术方案、核心功能实现、测试与部署、总结与展望 |
| AI 技术说明 | 重点阐述 AI 技术选型理由、集成方式、优化策略 |
| 创新点说明 | 明确列出技术创新点与应用创新点 |

### 2.4 在线演示（可选加分项）

| 要求项 | 具体要求 |
| --- | --- |
| 部署要求 | 提供可公网访问的在线演示地址 |
| 可用性 | 评审期间保持服务可用 |
| 体验账号 | 如需登录，须提供评审专用测试账号 |

## 3. 提交注意事项

- 所有材料须在截止时间前通过大赛官网统一提交。
- **API 密钥等敏感信息不得出现在公开仓库中**，须通过环境变量方式配置。
- 提交后不得修改，如有特殊情况须联系组委会处理。
- 材料不完整将影响评审结果，建议提前检查确认。

## 4. 评分维度

| 评分维度 | 权重 | 核心考察点 |
| --- | --- | --- |
| AI 技术深度 | 35% | AI 技术的应用深度、集成质量与创新性 |
| 创新性 | 25% | 选题创新、模式创新、交互创新 |
| 前端工程质量 | 10% | 前端代码质量、组件化架构、性能优化 |
| 实用性 | 10% | 真实场景价值、问题解决能力 |
| 用户体验 | 10% | UI/UX 设计、交互流畅度、易用性 |
| 社会价值与商业潜力 | 10% | 社会意义、商业前景、可持续性 |

### 4.1 AI 技术深度（35%）

| 考察点 | 占比 | 评分标准 |
| --- | --- | --- |
| 大模型集成质量 | 8% | 合理选择并高质量集成 LLM，Prompt 设计精巧，输出稳定可控 |
| Agent / 工作流设计 | 8% | 是否实现 AI Agent 或复杂 AI 工作流，具备规划、工具调用、自主决策能力 |
| RAG 技术应用 | 6% | 是否实现 RAG 架构，检索策略合理，生成质量因检索增强显著提升 |
| 多模态能力 | 5% | 是否集成多种模态（文本、图像、语音、视频），融合自然流畅 |
| AI 安全与可控性 | 4% | 输出的安全性、可解释性，内容过滤与兜底机制 |
| MCP / 工具集成 | 4% | 通过 MCP 协议或 Function Calling 实现 AI 与外部工具/数据源集成 |

### 4.2 创新性（25%）

| 考察点 | 占比 | 评分标准 |
| --- | --- | --- |
| 选题创新 | 10% | 是否发现独特的应用场景或未被满足的需求 |
| 技术方案创新 | 8% | AI 技术的组合应用是否有新意 |
| 交互模式创新 | 7% | 人机交互方式是否有创新 |

### 4.3 前端工程质量（10%）

| 考察点 | 占比 | 评分标准 |
| --- | --- | --- |
| 前端代码质量 | 4% | TypeScript 规范、组件结构清晰、可维护、无明显 Bug |
| 组件化与架构设计 | 3% | 组件划分合理、状态管理规范、模块解耦、可复用 |
| 前端性能优化 | 3% | 首屏加载、渲染性能、资源优化（懒加载、代码分割、缓存） |

### 4.4 实用性（10%） / 用户体验（10%） / 社会价值与商业潜力（10%）

| 维度 | 考察点 | 占比 |
| --- | --- | --- |
| 实用性 | 场景真实性 / 解决方案有效性 | 5% / 5% |
| 用户体验 | UI 设计与视觉表现 / 前端交互体验 / AI 交互体验 | 4% / 3% / 3% |
| 社会价值与商业潜力 | 社会价值 / 商业潜力 | 5% / 5% |

## 5. 评分说明

- 各维度百分制评分，最终按权重加权计算总分。
- 评审专家组由高校教师、企业技术专家、AI 行业从业者组成。
- 每件作品由不少于 3 位评审专家独立评分，取平均分。
- 决赛阶段增加现场答辩评分（占决赛总分 30%）。

## 6. 比赛环境与技术栈建议

作品须基于主流前端 Web 技术体系开发，技术选型不做强制限定，推荐：

- 前端框架：React + Next.js 14+（首选）/ Vue 3 + Nuxt 3 / Svelte 5 + SvelteKit / React + Vite / Astro
- UI 与样式：Tailwind CSS（强烈推荐）、shadcn/ui、Ant Design / Element Plus、Framer Motion / GSAP
