## 1. 环境要求

| 项 | 版本要求 | 说明 |
| --- | --- | --- |
| Python | 3.10+（实测 3.14.7） | 后端服务与脚本 |

## 3. 环境变量模板

`backend/.env.example`（复制为 `.env` 使用）：

```env
# Mock 开关：1 = 无 Key 时返回虚构 Matter 数据（前端联调用），0 = 关闭
LLM_ENABLE_MOCK=1

# 大模型 API Key。留空 + LLM_ENABLE_MOCK=1 时自动走 mock
LLM_API_KEY=

# 服务端口
PORT=8000

# -------------------- 以下均为可选，不填就用默认值 --------------------
# 文本长度上限（字符数），默认 3000；填 0 表示不限制
# MAX_TEXT_LENGTH=3000

# 大模型接口地址，默认 https://api.openai.com/v1
# LLM_BASE_URL=https://api.openai.com/v1

# 模型名称，默认 gpt-4o
# LLM_MODEL=gpt-4o
```

| 变量 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `LLM_ENABLE_MOCK` | 否 | `0` | `1` = 无 Key 时降级返回虚构数据；有 Key 时该开关也决定真实调用失败后是否降级 |
| `LLM_API_KEY` | 生产必填 | 空 | 大模型 API Key |
| `LLM_BASE_URL` | 否 | `https://api.openai.com/v1` | 换成国内平台时改这里 |
| `LLM_MODEL` | 否 | `gpt-4o` | 需与 Key、Base URL 匹配 |
| `PORT` | 否 | `8000` | 服务端口 |
| `MAX_TEXT_LENGTH` | 否 | `3000` | 文本长度上限（字符）；`0` = 不限制 |

> 🔐 **密钥安全**：`.env` 已在 `.gitignore` 中忽略，仓库里只保留 `.env.example`。比赛明确要求 API 密钥不得出现在公开仓库中。

## 4. 安装与启动

```powershell
cd backend

# 1) 创建虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1            # Windows PowerShell
# source .venv/bin/activate             # macOS / Linux

# 2) 安装依赖
pip install -r requirements.txt

# 3) 准备配置
copy .env.example .env                  # macOS / Linux: cp .env.example .env

# 4) 环境自检（应输出「环境就绪 ✅」）
python check_env.py

# 5) 启动服务
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
# 或者： powershell -ExecutionPolicy Bypass -File .\run.ps1
#        bash run.sh
```

验证与回归：

```powershell
python smoke_test.py        # 10 项接口回归（含空文本、超长、CORS、Mock 性能）
python test_llm.py          # 验证真实大模型 Key 是否可用（--mock 可离线自检）
```

## 5. 配置真实大模型（密钥）

三种方式任选：

**方式一：交互式脚本（推荐）**

```powershell
powershell -ExecutionPolicy Bypass -File .\configure_env.ps1
```

会依次询问 API Key（隐藏输入）、Base URL、模型名、端口，写入 `.env`，并在配置了 Key 后自动关闭 Mock。

**方式二：手动编辑 `.env`**

```env
LLM_ENABLE_MOCK=0
LLM_API_KEY=<在此填入你的APIKey>
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o
```

**方式三：系统环境变量（不留文件）**

```powershell
$env:LLM_API_KEY="<在此填入你的APIKey>"; $env:LLM_MODEL="gpt-4o"; python -m uvicorn main:app --port 8000
```

改完配置**必须重启服务**，然后访问 `/health` 确认 `mode`：

- `mode = mock`：无 Key 且 `LLM_ENABLE_MOCK=1`，返回虚构数据（联调用）
- `mode = real`：检测到 `LLM_API_KEY`，走真实大模型

## 6. 前端联调配置

前端项目根目录建 `.env.local`：

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

后端已开放 CORS（允许所有来源），前端本地开发**不需要**配置 Vite 代理。可直接复用 `backend/for-frontend/api.js`。

局域网演示：后端用 `--host 0.0.0.0` 启动，把 `VITE_API_BASE_URL` 改成 `http://<本机IP>:8000`。

## 7. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `ModuleNotFoundError: No module named 'fastapi'` | 没装依赖或没激活虚拟环境 → `pip install -r requirements.txt` |
| 改了 `.env` 不生效 | 重启服务；`LLM_ENABLE_MOCK` 在模块导入时读取 |
| `mode` 一直是 real 但请求失败 | Key / Base URL / 模型名不匹配 → 跑 `python test_llm.py` 看具体错误 |
| 无 Key 又没开 Mock 时解析报错 | 预期行为：`LLM_API_KEY 未配置，无法解析通知` → 配 Key 或设 `LLM_ENABLE_MOCK=1` |
| 端口被占用 | 改 `PORT`，或杀掉占用进程 |
| 前端报跨域 | 确认后端已启动且是 CORS 全放开版本；`/docs` 能打开说明后端正常 |
| Windows PowerShell 脚本报语法错 | 含中文的 `.ps1` 必须保存为 **UTF-8 BOM** |
| 覆盖 A 发来的 `.py` 提示访问被拒绝 | 微信接收文件带只读属性：`(Get-Item .\文件.py).IsReadOnly = $false` |
