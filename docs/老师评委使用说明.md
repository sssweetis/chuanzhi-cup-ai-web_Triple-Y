# 老师 / 评委使用说明

> 当前在线地址：部署完成后由 C 填写。本文档不包含 API Key、账号密码或个人隐私信息。

## 1. 打开方式

用 Chrome / Edge 打开 C 提供的公网地址，例如：

```text
http://服务器公网IP/
```

无需登录，直接进入通知解析页面。

## 2. 推荐演示

### 文字通知

1. 在输入框粘贴 `docs/demo-kit/01-标准通知-奖学金.txt`
2. 点击「AI 智能解析」
3. 查看截止时间、材料清单、流程步骤和原文出处

### 截图 / PDF

1. 点击「截图/图片」上传 `docs/demo-kit/04-通知截图.png`
2. 或点击「PDF」上传 `docs/demo-kit/05-文字型通知.pdf`
3. 等待解析完成，检查材料与截止时间

### 补充通知对比

1. 点击「补充通知对比」
2. 原通知使用 `06-补充通知1-原通知.txt`
3. 补充通知使用 `07-补充通知1-补充通知.txt`
4. 查看变化和受影响待办，点击确认更新
5. 刷新页面，确认清单仍然保留

### 材料库追问

1. 上传 `01-标准通知-奖学金.txt` 和 `03-材料视频通知.txt`
2. 提问「视频有什么要求？」
3. 回答应附文件名、片段编号和原文依据

## 3. 使用限制

- 支持文字、截图和文字型 PDF；扫描版 PDF 请改用截图
- 图片建议不超过 5MB，PDF 不超过 10MB / 30 页
- 通知原文默认不超过 10,000 字符
- 演示数据使用浏览器会话隔离，刷新后同一会话仍可恢复
- 在线演示为临时环境；如果页面提示服务不可用，请联系 C

## 4. 隐私与安全

- 不要上传身份证、成绩单等真实个人材料；请使用演示虚构数据
- 不要在问题或输入框中粘贴 API Key
- 后端 Key 只保存在服务器环境变量或本机 `.env` 中，不会返回给浏览器
- 如果页面出现「服务暂时不可用」，请记录页面上的 request_id 并联系 C
