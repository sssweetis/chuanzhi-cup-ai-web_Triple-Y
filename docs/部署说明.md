# 部署与在线演示说明（C）

> 对应比赛可选加分项「在线演示」：提供可公网访问的地址，评审期间保持可用。

## 1. 本地运行（开发/演示）

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
# 前端
cd ..\frontend
npm install
npm run dev
```

- 后端健康检查：<http://127.0.0.1:8000/health>
- 接口文档：<http://127.0.0.1:8000/docs>

## 2. Docker 部署（推荐给服务器）

前提：服务器装好 Docker（含 compose 插件）。

```bash
# 1) 拉代码
git clone https://github.com/sssweetis/chuanzhi-cup-ai-web_Triple-Y.git
cd chuanzhi-cup-ai-web_Triple-Y

# 2) 准备配置（不要提交）
cp backend/.env.example backend/.env
# 编辑 backend/.env：LLM_ENABLE_MOCK / LLM_API_KEY / LLM_BASE_URL / LLM_MODEL
#                 TEAM_LLM_*（截图视觉模型，可选）

# 3) 启动
docker compose up -d --build

# 4) 验证
curl http://127.0.0.1:8000/health
```

- 镜像里已包含：FastAPI + uvicorn、pypdf（PDF）、RapidOCR + onnxruntime（本地 OCR 兜底）
- `backend/data/` 通过 volume 持久化（准备清单、文件片段索引）
- 容器内自带 HEALTHCHECK（30s 一次 /health）

## 3. Nginx 反向代理 + HTTPS（公网演示）

```nginx
server {
    listen 80;
    server_name demo.example.com;

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 180s;   # 真实模型解析可能要 10~30s，PDF/OCR 更久
        client_max_body_size 12m;  # 后端限制 PDF 10MB，这里留余量
    }

    location /health {
        proxy_pass http://127.0.0.1:8000/health;
    }

    # 前端静态文件（npm run build 产物）
    location / {
        root /var/www/tripley;
        try_files $uri $uri/ /index.html;
    }
}
```

> HTTPS 用 certbot：`certbot --nginx -d demo.example.com`

前端构建：

```bash
cd frontend
# 线上后端地址：在 .env.production 里写 VITE_API_BASE_URL=https://demo.example.com
npm run build      # 产物在 frontend/dist，上传到 /var/www/tripley
```

## 4. 部署检查清单

- [ ] `/health` 返回 `{"status":"ok","mode":"real"或"mock"}`
- [ ] `/docs` 能打开
- [ ] CORS 正常（前端域名能调 `/api/analyze`）
- [ ] `backend/.env` 不在 git 里（`git status` 看不到）
- [ ] 上传接口可用（图片 ≤5MB / PDF ≤10MB）
- [ ] 容器重启后数据还在（`docker compose restart` 后 GET 准备清单）
- [ ] 演示前把 `LLM_ENABLE_MOCK=0` 且 Key 可用（或明确标注 mock）

## 5. 无公网服务器时的替代方案

1. **内网穿透**：`cloudflared tunnel --url http://127.0.0.1:8000`（临时地址，演示够用）
2. **校园网 + Radmin VPN**：评审需要装客户端，不推荐给评委
3. 只提交演示视频 + 本地可运行仓库（在线演示是加分项，不是必需）
