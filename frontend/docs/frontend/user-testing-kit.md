# 用户测试执行套件

状态：待执行。需要 8–10 名同学参与。

## 目标

验证真实用户能否完成：

1. 从通知文字或截图生成任务
2. 看懂同日并行任务和重叠时间
3. 从错误状态恢复且不丢输入

## 参与者

- 8–10 名在校大学生
- 至少 3 名未使用过 Triple Y
- 至少 2 名有竞赛/奖学金/活动报名经验
- 不提前解释页面操作

## 三个任务

### 任务 1：录入并加入清单

给用户一段包含两个截止时间和三项材料的通知。要求：

- 粘贴文字
- 完成解析
- 找到最早截止时间
- 加入任务清单

记录：完成率、耗时、漏掉的截止时间/材料数量。

### 任务 2：处理并行任务

给用户一条包含三项同日任务的补充通知。要求：

- 找到 10:00–10:30 的完全重叠
- 指出哪项任务可转交
- 给其中一项添加子任务

记录：能否发现重叠、是否误解负责人、是否漏任务。

### 任务 3：错误恢复

让用户分别触发：

- 网络断开
- 上传格式不支持的文件
- 解析超过 90 秒后选择“换文字”

记录：用户是否理解下一步、输入是否保留、是否能恢复操作。

## 观察指标

- 任务完成率
- 完成时间
- 漏项数
- 满意度 1–5
- 第一次点击是否犹豫
- 是否尝试浏览器返回/刷新
- 是否注意到错误编号或恢复按钮
